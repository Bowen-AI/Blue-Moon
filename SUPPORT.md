# Support

Blue Moon is early and open source.

## Ask For Help

Use GitHub issues for:

- setup problems
- bug reports
- feature ideas
- event template suggestions
- accessibility concerns
- trust and safety concerns

Open an issue here:

https://github.com/Bowen-AI/Blue-Moon/issues

## Sponsor Or Donate

Sponsorship helps cover hosting, email tooling, design, moderation, accessibility work, and real-world community testing.

Use the GitHub Sponsor button if it appears on the repository. If sponsorship is not enabled yet, open an issue titled `Sponsorship or donation`.

Donations do not buy event approval, moderation preference, or influence over trust and safety decisions.
