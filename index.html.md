# Blue Moon Beige

Once in a blue moon, do something good.

Blue Moon Beige is the search-friendly home for Blue Moon, a lightweight platform for creating, finding, joining, completing, and sharing local good-action events. The first MVP focuses on cleanups, food help, community gardens, tree planting, and neighborhood support.

## Core Actions

- Find nearby good-action events.
- Create a one-off event.
- Create an organization and use an approval path for organization events.
- Join an event with public or private visibility.
- Share completed events and proof afterward.
